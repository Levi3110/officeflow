# Labelled example evidence

`simulation/` contains an actual run of the **test-double backend**, not a desktop run:

- `metrics.json`: the recorded run outcome and diagnostic statistics.
- `telemetry.sample.jsonl`: real OS sampler records from the simulation process and matching
  running Chrome processes. They do not prove that the agent browsed Chrome during this run.
- `audit.handoffs.jsonl`: the five recorded authority transfers.
- `comparison.ods`, `report.odt`: artifacts generated by the simulation test double.
- `doctor.macos.json`: actual desktop preflight result at handoff.
- `activity-assessment.json`: the seven requested capability checks, with simulation/desktop
  evidence reported separately; this is not an authenticity or competition score.

The catalog prices are fictional; the loopback source URLs are only available when that run's
fixture server is running. Full journal and source evidence remain in the local `runs/` folder.
No timing, process, mouse or keyboard telemetry has been fabricated to represent live activity.

`optimization/` includes raw fresh-process benchmark trials and the frozen baseline source.
`input-unavailable.jsonl` is an actual native permission check that emitted status only; it
contains no input observations or human baseline. See `docs/OPTIMIZATION.md` for measured
changes and the local stopping condition. Benchmark data describes simulation core costs.

`native/` contains the successfully completed **real desktop** workflow: actual GUI-produced
files, complete audit/input/OS records, source evidence, the 7/7 activity assessment and a
provenance summary. Read its [validation record](native/README.md) for exact limits and earlier
development failures. Native evidence and simulation evidence are kept explicitly labelled.

`recorded-demo/` contains the later run's permission checks, output files, metrics, activity
assessment and verified video metadata. The full 1080p MP4 is a local artifact under `dist/`,
with its original MOV and QA frames under `runs/`; video/screenshot pixels are excluded from Git.

`human-05-benchmark/` contains aggregate results, CSV and provenance for the single-person
manual comparison. Read the [case study](../docs/HUMAN_05_BENCHMARK.md) for timing differences,
individual variability, resource/focus limitations and the unassigned weighted score. Raw human
input and OS traces are archived locally and excluded from Git.
