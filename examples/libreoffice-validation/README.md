# Native LibreOffice file compatibility

Actual validation with installed LibreOffice 26.8.1.1, using an isolated headless profile.
`verification.json` records the native round trip of empty templates and the existing
simulation-generated comparison/report, including 20 cell checks and recalculated formulas.

This is a file compatibility check, not GUI execution, human activity or an authenticity score.
Full output files and process logs are retained under local `runs/libreoffice-validation/`.
